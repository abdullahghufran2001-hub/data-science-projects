# 🧠 Data Science Projects Repository

Welcome to the **Data Science Projects** repository!

This repository contains practical Data Science projects focused on Data Analysis, Machine Learning, Predictive Analytics, Recommendation Systems, Data Visualization, and Interactive Dashboards.

The projects are developed using Python and modern Data Science libraries to transform raw data into meaningful insights, predictions, and intelligent business solutions.

- Create Interactive Dashboards

⚙️ Installation

Clone the repository:

git clone https://github.com/abdullahghufran2001-hub/data-science-projects.git

Move into the project folder:

cd data-science-projects

Install required libraries:

pip install -r requirements.txt
▶️ How to Run Projects
Run Python Script

Navigate to the Python source code folder:

cd python

Run the main Python project:

python streamflix.py

Make sure the required datasets are available:

ratings.csv
reviews.csv
subscribers.csv
titles.csv
watch_history.csv
watchlist.csv
